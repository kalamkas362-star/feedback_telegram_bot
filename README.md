# Сабақ рефлексиясына арналған Telegram-бот

Сабақ соңында оқушылар бот арқылы көңіл күйін, тақырыпты түсіну деңгейін және қысқа пікірін жібереді. Жауаптар SQLite дерекқорына сақталады, ал мұғалімге Telegram хабарламасы жіберіледі.

## Мүмкіндіктері

- Көңіл күйі: 😄 Өте жақсы / 🙂 Жақсы / 😐 Орташа / 😕 Қиын болды.
- Түсіну деңгейі: толық түсіндім / жартылай түсіндім / қосымша түсіндіру қажет.
- Еркін пікір: оқушы сабақта не ұнағанын немесе нені жақсартуға болатынын жазады.
- Мұғалімге арналған /stats және /export пәрмендері.
- Telegram токені кодқа енгізілмейді, .env файлы Git арқылы жіберілмейді.

## 1. Telegram-да бот ашу

1. Telegram-нан ресми @BotFather аккаунтын ашыңыз.
2. /newbot пәрменін жіберіп, боттың атауы мен username-ін таңдаңыз.
3. BotFather берген API token-ді көшіріп алыңыз. Оны ешкімге жібермеңіз және GitHub-қа жарияламаңыз.
4. Жаңа ботыңызды Telegram-нан ашып, Start батырмасын басыңыз.

## 2. Компьютерде іске қосу (Windows)

Python 3.10 немесе жаңарақ нұсқасы орнатылған болсын. PowerShell ашып, орындаңыз:

```powershell
git clone https://github.com/kalamkas362-star/feedback_telegram_bot.git
cd feedback_telegram_bot
python -m venv .venv
.venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Жобаның ішіндегі .env файлын ашып, BOT_TOKEN мәніне BotFather берген token-ді қойыңыз:

```dotenv
BOT_TOKEN=BotFather_берген_нақты_token
ADMIN_CHAT_ID=123456789
DATABASE_PATH=feedback.db
```

Енді Telegram-да өз ботыңызды ашып, Start басыңыз. Мұғалімге жауап жіберу үшін:

1. .env файлына әзірге ADMIN_CHAT_ID жолын бос қалдыруға болады.
2. Ботты іске қосыңыз: `python bot.py`.
3. Telegram-да өз ботыңызға /myid жіберіңіз. Бот сандық chat ID көрсетеді.
4. Ботты терминалда Ctrl+C арқылы тоқтатыңыз.
5. .env файлына `ADMIN_CHAT_ID=көрсетілген_сан` деп енгізіңіз де қайта іске қосыңыз.
6. Мұғалім ботқа өзі де Start басуы керек. Оқушы сауалнаманы аяқтаған кезде жауап мұғалімге келеді.

## 3. Ботты іске қосу

```powershell
python bot.py
```

Терминал жабылса, жергілікті бот тоқтайды. Сабақ уақытында жұмыс істеуі үшін компьютер мен терминалды қосулы қалдырыңыз немесе төмендегі хостингті қолданыңыз.

## 4. Интернетте тәулік бойы жұмыс істету

Бұл бот polling режимінде жұмыс істейді, сондықтан GitHub Pages-ке орналастыруға болмайды. Оны Render сияқты Python background worker қолдайтын хостингке орналастырыңыз:

1. Render-де New → Blueprint таңдап, осы GitHub репозиторийін қосыңыз. Репозиторийде render.yaml бар.
2. Сервис параметрлеріндегі Environment бөлімінде `BOT_TOKEN` және `ADMIN_CHAT_ID` мәндерін орнатыңыз.
3. Logs ішінен боттың іске қосылғанын тексеріңіз.
4. Маңызды: Render уақытша файлдық жүйесінде SQLite базасы қайта deploy кезінде жоғалуы мүмкін. Тұрақты disk қосып `DATABASE_PATH` мәнін сол жолға бағыттаңыз немесе PostgreSQL секілді сақталатын дерекқорды қолданыңыз.

## Мұғалім пәрмендері

- `/start` — сауалнаманы бастау.
- `/myid` — ағымдағы Telegram chat ID-ін білу.
- `/stats` — жауаптардың қысқаша статистикасы (тек ADMIN_CHAT_ID иесіне).
- `/export` — Excel бағдарламасында ашылатын CSV файлды жүктеу (тек мұғалім).
- `/cancel` — ағымдағы сауалнаманы тоқтату.

## Қауіпсіздік

- Нақты токенді ешқашан bot.py ішіне не GitHub-қа енгізбеңіз.
- Жергілікті құпия мәндерді тек .env файлына енгізіңіз; бұл файл .gitignore арқылы еленбейді.
- Егер token жария болып кетсе, @BotFather арқылы бірден жаңартыңыз.
- Әр оқушы үшін сауалнама жауаптары боттың жергілікті SQLite базасына жазылады. Хостингте сақталу параметрін бөлек тексеріңіз.

## Қате шықса

- `BOT_TOKEN табылмады`: .env барын және BOT_TOKEN дұрыс енгізілгенін тексеріңіз.
- Мұғалімге хабарлама келмейді: ADMIN_CHAT_ID-ді тексеріп, мұғалім ботқа Start басқанын растаңыз.
- Бот жауап бермейді: терминалдағы немесе хостингтегі Logs журналын қараңыз. Бір token-мен екі polling процесін бір уақытта іске қоспаңыз.
