# Google Apps Script — тегін орналастыру

Бұл нұсқа Render-дегі ақылы Background Worker-ді қолданбайды. Telegram webhook Google Apps Script web app-қа келеді, ал оқушылардың жауаптары Google Sheets кестесінде сақталады.

Толық нұсқаулық: [apps-script/README.md](README.md).

**Қауіпсіздік:** нақты Telegram токенін осы жария GitHub репозиторийіне жазбаңыз. Токенді өзіңіздің жеке Google Apps Script жобаңыздағы `BOT_TOKEN` мәніне ғана енгізіңіз.
