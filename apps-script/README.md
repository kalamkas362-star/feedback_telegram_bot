# Telegram рефлексия ботын тегін орналастыру (Google Apps Script)

Бұл нұсқа ботты компьютер немесе PowerShell ашық тұрмай-ақ жұмыс істетуге арналған. Telegram жаңартулары webhook арқылы Google Apps Script web app-қа келеді; жауаптар Google Sheets кестесінде сақталады. Webhook үшін жауаптар HtmlService арқылы беріледі, себебі ContentService жауабы кей жағдайда Telegram күткен 200 орнына 302 қайта бағыттау қатесін беруі мүмкін.

## Маңызды — токен қауіпсіздігі

- Нақты BotFather токенін осы жария GitHub репозиторийіне жазбаңыз.
- Токенді тек өзіңіздің Google Apps Script жобаңыздағы `BOT_TOKEN` мәніне енгізіңіз.
- Бұл бот үшін бұрын алған мұғалімнің Telegram ID нөмірін `ADMIN_CHAT_ID` мәніне енгізуге болады.
- Орналастыруды аяқтағанда локалды Python ботты `Ctrl+C` арқылы тоқтатыңыз. Бір токен бір уақытта polling және webhook режимінде жұмыс істемеуі керек.

## Орнату қадамдары

### 1. Google Apps Script жобасын ашу

1. [script.google.com](https://script.google.com/) сайтына өз Google аккаунтыңызбен кіріңіз.
2. **New project / Жаңа жоба** таңдаңыз.
3. Жоба атауын, мысалы, `Сабақ рефлексиясы боты`, деп өзгертіңіз.

### 2. Кодты көшіру

1. GitHub-тағы [Code.gs файлын ашыңыз](https://github.com/kalamkas362-star/feedback_telegram_bot/blob/main/apps-script/Code.gs).
2. **Raw** батырмасын басыңыз.
3. Барлық кодты көшіріп, Google Apps Script редакторындағы `Code.gs` ішіне қойыңыз (ескі үлгі кодты толық ауыстырыңыз).
4. Кодтың жоғарғы жағындағы мына екі жолды өз деректеріңізбен ауыстырыңыз:

```javascript
const BOT_TOKEN = 'BotFather_берген_нақты_token';
const ADMIN_CHAT_ID = 'Telegram_мұғалім_ID_нөмірі';
```

Токен мен ID-ді тырнақшаның ішіне енгізіңіз. `PASTE_YOUR...` үлгілерін қалдырмаңыз. Нақты токенді GitHub-тағы файлға енгізбеңіз.

5. **Save / Сақтау** батырмасын басыңыз.

### 3. Web app ретінде жариялау

1. Жоғарғы оң жақтан **Deploy → New deployment** таңдаңыз.
2. **Select type** жанындағы тісті доңғалақ/таңдау белгісін басып, **Web app** таңдаңыз.
3. **Execute as / Выполнять от имени** бөлімінде **Me / Мен** таңдаңыз.
4. **Who has access / У кого есть доступ** бөлімінде **Anyone / Все** таңдаңыз. Telegram webhook серверге Google аккаунтымен кірмей сұраныс жібереді, сондықтан веб-қосымшаға сырттан қолжетімділік қажет.
5. **Deploy** батырмасын басыңыз, Google рұқсаттарын растаңыз.

Егер кодты бұрын жариялап қойған болсаңыз: **Deploy → Manage deployments** ашып, жұмыс істеп тұрған deployment жанындағы қарындаш белгісін басыңыз, **Version → New version** таңдаңыз да **Deploy** басыңыз. Кодты редакторда сақтау жарияланған нұсқаны автоматты түрде жаңартпайды.
6. Жарияланған URL-ді көшіруге болады, бірақ Telegram webhook үшін оны қолмен енгізудің қажеті жоқ — `initializeBot()` функциясы URL-ді өзі оқиды.

Егер Google аккаунтыңызда **Anyone** таңдауы болмаса, ұйым/аккаунт саясатымен шектелген болуы мүмкін.

### 4. Telegram webhook-ын қосу және Google кестесін жасау

1. Код редакторына қайтыңыз.
2. Жоғарғы жағындағы функциялар тізімінен **initializeBot** таңдаңыз.
3. **Run / Выполнить** батырмасын басыңыз.
4. Алғашқы іске қосуда Google сұрайтын рұқсаттарды беріңіз. Бұл функция Google кестесін жасау және Telegram API-мен байланысу үшін қажет.
5. Іске қосу аяқталған соң **Execution log / Журнал выполнения** бөлімін ашыңыз. 
6. Telegram-да ботыңызға жаңа `/start` жіберіп тексеріңіз. Егер жауап болмаса, редактордың сол жағындағы **Executions** бөлімінен `doPost` орындалған-орындалмағанын және қатесін тексеріңіз. Telegram webhook қатесін `getWebhookInfo` арқылы тексеруге болады. Онда `Жауаптар Google кестесінде сақталады` дегеннен кейін кесте сілтемесі жазылады.
6. Сол Google Sheets файлын ашсаңыз, оқушылардың жауаптары сол жерде жиналады.

### 5. Ботты тексеру

1. Telegram-да өз ботыңызды ашып, `/start` жіберіңіз.
2. Көңіл күйін және түсіну деңгейін таңдаңыз.
3. Пікір жазыңыз немесе **Өткізіп жіберу** батырмасын басыңыз.
4. Оқушы тек «Рақмет! Кері байланысың қабылданды» деген хабарламаны көреді. Жеке таңдаулар мен пікір мұғалімге жіберіледі және Google Sheets-ке сақталады.
5. Мұғалім `/stats` арқылы қысқаша статистиканы, `/export` арқылы CSV файлын ала алады. Мұғалімнің Telegram-ында ботпен диалогты алдын ала ашып, **Start** басқан болуы қажет.

## Қолданылатын файлдар мен қызметтер

- `apps-script/Code.gs` — Google Apps Script webhook нұсқасы.
- Google Sheets — рефлексия жауаптарының тұрақты кестесі.
- `bot.py` — компьютерде немесе кәдімгі Python серверінде іске қосылатын нұсқа.
- Render-дегі осы репозиторийдің `render.yaml` конфигурациясы Background Worker сұрайды; ол Render Free жоспарына кірмейді. Тегін нұсқа үшін осы Apps Script нұсқаулығын қолданыңыз.

## Қате шықса

- **Бот үнсіз:** `initializeBot()` іске қосылды ма, Deploy кезінде қолжетімділік `Anyone` болды ма, және Telegram токені дұрыс па — тексеріңіз.
- **Мұғалімге хабарлама келмейді:** `ADMIN_CHAT_ID` дұрыс сан екенін және мұғалім ботқа **Start** басқанын тексеріңіз.
- **Google кестесі ашылмайды:** `initializeBot()` іске қосылған Google аккаунтпен кіріңіз; Execution log ішіндегі кесте сілтемесін тексеріңіз.
- **Бұрынғы Python процесі әлі жүріп тұр:** PowerShell терезесінде `Ctrl+C` басыңыз. Webhook қосылғаннан кейін polling процесін қалдырмаңыз.

Google Apps Script-тің өз квоталары мен шектеулері бар; өте үлкен көлемдегі қолдануға арналған қызмет емес, бірақ сыныптағы шағын рефлексия сауалнамасына жарайтын тегін тәсіл.
